## BMI Calculator (CLI Version)
A simple, user-friendly Python command-line application that calculates a user's Body Mass Index (BMI) based on their weight and height. It provides a health category classification based on international standards.

## 🚀 Features
* Input Validation: Handles non-numeric inputs and ensures weight/height are positive numbers.
* Accurate Calculation: Uses the standard formula: BMI = {weight (kg)} / {height^2 (m^2)}.
* Health Categorization: Classifies results into Underweight, Normal weight, Overweight, or Obese.
* Clean Interface: Easy-to-read terminal output.

## 🛠️ Requirements
* Python 3.x installed on your system.
* A code editor like VS Code.
