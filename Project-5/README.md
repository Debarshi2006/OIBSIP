## Random Password Generator (Python)
A lightweight, command-line interface (CLI) application that allows users to generate secure, customized passwords based on their specific needs.

## 📝 Description
This is Project 5 of the Oasis Infobyte Python Programming Internship.This project was developed as part of a Python Programming challenge. It focuses on the core concepts of randomization and user input handling. The tool allows users to define the length of their password and choose whether to include numbers and special characters.

## ✨ Features
* Custom Length: Users can specify exactly how many characters they want.

* Complexity Options: Toggle between letters-only or include numbers and symbols.

* Input Validation: Handles basic errors to ensure the program doesn't crash if a user enters invalid data.

* Secure Randomization: Uses Python's random module for unpredictable character selection.

## 🛠️ Logic Flow
The program follows a simple linear logic to ensure efficiency:

* Collect user preferences.

* Combine selected character sets into a single "pool."

* Iterate through a loop to pick random characters from that pool.

* Display the final string to the user.

## 📚 Concepts Learned
* Modules: Importing and using random and string.

* Loops: Using for loops to repeat actions.

* Conditional Logic: Using if/else to customize the character pool.

* Data Types: Converting string inputs to integers for calculations.
