# 🌦️ Python CLI Weather App

A simple Command Line Interface (CLI) application that fetches real-time weather data using the OpenWeatherMap API. 

## 🚀 Features
- Fetches current temperature and weather conditions.
- Uses the `requests` library for API communication.
- Securely handles API keys using `python-dotenv`.
- Includes basic error handling for invalid city names.
